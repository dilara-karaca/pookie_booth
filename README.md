# Pookie Booth

A free online photobooth. Pick a frame, take photos in the browser, and download a PNG strip. Photos are processed on the device and are not uploaded.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL. Camera access needs `localhost` or HTTPS.

## Scripts

- `npm run dev` — development server
- `npm run test` — unit tests
- `npm run build` — typecheck and production build
- `npm run preview` — preview the production build

## Rename the brand

Edit `src/lib/brand.ts`.
